# WSCLauncher 1.2.3

Hook engine stability release, validated on Android 11 and Android 15 with World Soccer Champs 468.

## Fixes

- **Fixed a guest process crash triggered by the game's ad SDK (Android 7–13, LSPlant backend).** Exceptions thrown by hooked methods now keep their original type instead of being wrapped in `RuntimeException`. Optional Google Play services probes (e.g. `DynamiteModule`) rely on catching `ClassNotFoundException` to degrade gracefully — that path works again.
- **Fixed a first-run crash on Android 15 (Pine backend).** Every hooked method is now pre-compiled with `Pine.compile()` before `Pine.hook()`, so the backup method never runs through the interpreter bridge. A concurrent GC compaction can no longer corrupt a half-executed interpreted frame (the previous SIGSEGV in `ExecuteSwitchImplCpp`).
- **Anti-tamper safe mode: `libart` is never patched.** The game's protection layer verifies the ART runtime's integrity and deliberately kills the process when it detects inline hooks there. The LSPlant bridge now runs entirely in "direct hooks" mode, which is invisible to that check.

## Hook engine changes

- LSPlant's internal inline hooking now uses **shadowhook** (the same engine used by native mods). Dobby 1.2 was removed from the build: its hooks silently corrupt modern `libart` internals on Android 14+/15.
- New **native LSPlant self-test**: before installing any hook, the bridge exercises the exact call chain that used to crash (`ToReflectedMethod` → `FromReflectedMethod` → `GetMethodShorty`). If anything fails, the backend is discarded and the launcher falls back to Pine — the game always opens.
- Backend selection was rewritten around a pure, unit-tested probe order. A forced backend preference (Settings → Developer) is still honored first, but it can no longer crash the guest: failures fall back automatically to the other backend.
- Diagnostics (`wsc-diagnostico`) now report the active backend (`hooker=LSPlant|Pine`) and Pine pre-compilation stats.

## Build changes

- `assembleRelease` without the `WSC_RELEASE_*` environment variables now signs with the debug key, so local/QA builds remain installable while staying non-debuggable. This matters because a debuggable guest on Android 14+ switches ART to index-based JNI ids, a mode the LSPlant path cannot survive.
- Version 1.2.3 (versionCode 26).

## Tests

99 unit tests (10 new `HookerCallbackTests`, 9 new `HookerBackendSelectionTests`) pass in both debug and release variants, plus lint and the native host test suite.
