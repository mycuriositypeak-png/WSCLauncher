## WSCLauncher 1.0.4

### Crash Fix

Fixes WSC 468 closing a few seconds after opening when the network allows ads. The launcher adapts the context used in ads SDK initialization to present the correct package and UID to Google services. The fix does not add internal DNS nor change the device's DNS.

### Game Data Export

In **Settings → Game Data → Export Game Data**, choose a version and the ZIP destination:

- **Complete:** all accessible regular files from the launcher's private directory, including resources, mods, logs and caches.
- **Light:** saves, backups, configurations and databases, without logos, adboards, resource packages and caches.

Export works without root, shows a bar with percentage and continues during screen rotation. Save the match before: the launcher closes its own game process before copying. Files are in `data/` inside the ZIP, accompanied by a manifest with paths, sizes and SHA-256. This version does not include automatic import.

### Updates and Downloads

This release maintains the official **`dev.wsc.launcher`** package and the project's release signature to update the original installation, preserving its data. It does not use the separate test APK package.

- **Universal:** contains both architectures.
- **ARM64:** for the ARM64 version of the game.
- **ARM32:** for the ARM32 version of the game, including on ARM64 devices.
- **Player Roles Picker:** native mod example package for compatible builds.

The SHA-256 sums are in `SHA256SUMS.txt`. The launcher does not include World Soccer Champs, its APK, assets or proprietary libraries.
