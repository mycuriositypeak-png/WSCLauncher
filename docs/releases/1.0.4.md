## WSCLauncher 1.0.4

### Correção de crash

Corrige o encerramento do WSC 468 alguns segundos após abrir quando a rede permite anúncios. O launcher adapta o contexto usado na inicialização do SDK de anúncios para apresentar o pacote e UID corretos aos serviços Google. A correção não adiciona DNS interno nem altera o DNS do aparelho.

### Exportação dos dados do jogo

Em **Configurações → Dados do jogo → Exportar dados do jogo**, escolha uma versão e o destino do ZIP:

- **Completa:** todos os arquivos regulares acessíveis da pasta privada do launcher, incluindo recursos, mods, logs e caches.
- **Leve:** saves, backups, configurações e bancos de dados, sem logos, adboards, pacotes de recursos e caches.

A exportação funciona sem root, mostra uma barra com porcentagem e continua ao girar a tela. Salve a partida antes: o launcher fecha seu próprio processo do jogo antes da cópia. Os arquivos ficam em `data/` dentro do ZIP, acompanhados de um manifesto com os caminhos, tamanhos e SHA-256. Esta versão não inclui importação automática.

### Atualização e downloads

Esta release mantém o pacote oficial **`dev.wsc.launcher`** e a assinatura de release do projeto para atualizar a instalação original, preservando seus dados. Não usa o pacote separado dos APKs de teste.

- **Universal:** contém as duas arquiteturas.
- **ARM64:** para a versão ARM64 do jogo.
- **ARM32:** para a versão ARM32 do jogo, inclusive em aparelhos ARM64.
- **Player Roles Picker:** pacote de exemplo de mod nativo para builds compatíveis.

As somas SHA-256 estão em `SHA256SUMS.txt`. O launcher não inclui World Soccer Champs, seu APK, assets ou bibliotecas proprietárias.
